# 图证校对板
给编辑、设计者和审核者的单图人工标注交接工具。输入本地PNG/JPEG/WebP，标问题位置、改法与状态，输出PNG、Markdown、含工作图的JSON备份。

无需账号或后端。运行 `node build.cjs` 生成单文件 `index.html`；本地用 `python3 -m http.server 8813`。测试 `node --test tests/core.test.cjs`。经典脚本核心导出AppCore，页面不加载第三方资源。

最多12条；原文件≤10MiB/2000万像素/单边12000；工作图最长边1600，不放大。透明图在白底合成。原图保留，不修改原文件。状态由用户输入，不是自动检测或人工审核证明。图面仅当前标注，导出每条单独缩略图，不叠画多个编号。边缘编号向内收；百分比为精确位置。建议先保存或导出备份再切换图片。

示例是故意包含日期、合计错误的虚构海报，不是真实商业案例。180+60=240为确定性演示校核；工具不会自动发现或修复该错误。JSON导入校验结构、枚举、数量、坐标、图像MIME/base64、大小和实际解码尺寸。

坐标变换采用contain；容忍1e-9像素浮点误差后钳制0–1。PNG逐字测宽折行，行内空白合并；文件名超过60字符在PNG摘要截断，完整名保留于JSON/Markdown。浏览器本机保存失败会提示另存JSON；浏览器清理可能造成丢失。

V1.0.0；本地测试和发布核验详见批次上级目录的验收报告。
